# UnoPoteto-LiveTranslate
UnoPoteto Live Translate - Reference and Documentation

## 🎧 About Translation Accuracy

There is no absolute "correct" translation.

Language is shaped by culture, context, and experience.
Even native speakers change how they use language depending on situation.

For example:

* Formal vs casual speech
* Broken grammar that still conveys meaning
* Emotional nuance beyond words

Sometimes, imperfect language carries more feeling.

Like:

* A child learning to speak
* A non-native speaker trying to communicate
* Simple or broken phrases that still reach people

These are not "wrong".
They are part of communication.

---

## 🎮 About This Project

This is not a professional translation service.

High-accuracy translation is already provided by tools like:

* Google Translate
* DeepL

This project focuses on:

> Real-time voice in gaming environments

---

## ⚠ Positioning

* This is NOT a replacement for professional translation
* This is NOT aiming for perfect accuracy
* This is NOT competing with existing services

---

## 🎯 Purpose

This system is designed for:

* Live communication
* Fast understanding
* Situational awareness in games

Not for:

* Official documents
* Formal communication
* Linguistic correctness

---

## 🧭 Philosophy

> Translation is not about correctness.
> It is about connection.

---

## 🔚 Final Note

Please do not apply excessive expectations or strict evaluation standards.

This system exists in a different context.
