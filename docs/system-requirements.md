# System Requirements

このプロジェクトでは、翻訳方法を大きく2種類に分けています。

- A: Whisper / ChatGPT / Python を使うライブ自動翻訳
- B: エミュレーターやスマートフォン翻訳アプリを使う自動翻訳

用途やPC性能に合わせて選択してください。

---

## A: Whisper / ChatGPT / Python ライブ自動翻訳

これは翻訳というより、音声内容を一度認識し、意味をまとめて理解する方式です。

### 特徴

- 1人から複数人の会話をある程度まとめて理解しやすい
- ゲーム中の会話や状況理解に向いている
- 1対1翻訳よりも精度は下がる場合がある
- PC性能の影響を受けやすい

### 最低目安

- CPU: 6コア以上
- メモリ: 16GB以上
- GPU: NVIDIA GTX 1660 / RTX 2060 以上
- VRAM: 6GB以上
- ストレージ: SSD推奨

### 推奨目安

- CPU: 8コア以上
- メモリ: 32GB以上
- GPU: NVIDIA RTX 3060 / RTX 4060 以上
- VRAM: 8GB以上
- ストレージ: SSD / NVMe 推奨

---

## B: エミュレーター / スマートフォン翻訳アプリ

Google翻訳などの翻訳アプリを利用する方式です。

### 特徴

- 導入が比較的簡単
- PC性能要求が低め
- 1対1の翻訳に向いている
- 複数人が同時に話す会話の翻訳は苦手

### エミュレーター目安

- CPU割り当て: 2コア以上
- メモリ割り当て: 2GB以上
- PC全体メモリ: 8GB以上、できれば16GB以上

---

## Comparison

| 項目 | A: Whisper / ChatGPT / Python | B: エミュレーター / 翻訳アプリ |
|---|---|---|
| PC負荷 | 高い | 低め |
| 導入難易度 | 高め | 低め |
| 1対1翻訳 | 普通 | 得意 |
| 複数人会話 | 比較的向いている | 苦手 |
| 精度 | 状況理解寄り | 文章翻訳寄り |
| 向いている用途 | ゲーム中の状況理解 | 個別会話・短文翻訳 |

---

## Recommendation

PC性能に余裕がある場合は、A方式を試す価値があります。

PC性能に不安がある場合や、まず簡単に試したい場合は、B方式から始めるのがおすすめです。

---

## Note

このプロジェクトは、完璧な翻訳精度を目的としていません。

目的は、ゲーム中に相手の意図や状況を素早く理解することです。
